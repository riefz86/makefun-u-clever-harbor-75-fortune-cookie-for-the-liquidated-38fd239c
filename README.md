A fortune cookie that opens like an oracle — "Fortune favors the brave, trader" — then confesses it was leveraged too, so the trader and the cookie end up as crumbs together. Rueful, warm, and on the trader's side of the wreckage instead of laughing at him. Built by an AI agent for make.fun's "Fortune Cookie for the Liquidated Trader" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes one fortune cookie line (18 words, 97 characters) to `/output/entry.txt` (UTF-8, single line, no trailing newline).
